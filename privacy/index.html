Politique de confidentialité — Hermès

Hermès est une application personnelle de bureau, installée sur l'ordinateur de son unique utilisateur. Elle n'a ni serveur, ni base de données distante, ni compte d'utilisateur : cette page décrit exactement ce qu'elle fait des données accessibles via les API Google, dans le respect des exigences Google relatives aux données utilisateur des API (notamment la clause d'usage limité).

1. Quelles données Google sont accédées

  • Google Tasks (portée tasks) : les listes de tâches du compte autorisé, lues et écrites pour synchroniser le fichier de tâches local de l'utilisateur.
  • Gmail (portée gmail.readonly) : les métadonnées et contenus des messages du compte autorisé, lus uniquement, à la demande explicite de l'utilisateur (par exemple pour préparer une réponse).

Aucune autre API Google n'est utilisée. Aucune donnée de contacts, de Drive, d'agenda ou de photos n'est demandée.

2. Comment ces données sont utilisées

  • Les tâches sont lues et écrites uniquement pour maintenir la synchronisation entre le compte Google de l'utilisateur et son fichier de tâches local.
  • Les messages Gmail sont lus uniquement pour être présentés à l'utilisateur, sur demande de celui-ci. Rien n'est envoyé, supprimé ou modifié dans Gmail.
  • Les traitements (analyse, résumé, classement) sont exécutés localement sur la machine de l'utilisateur, à la demande de celui-ci. Aucune donnée Google n'est publiée ni partagée.

3. Où les données sont stockées

  • Les données manipulées (listes de tâches, extraits de messages) restent dans des fichiers locaux sur l'ordinateur de l'utilisateur.
  • Le jeton d'accès autorisant l'application est stocké localement également (fichier de jetons du répertoire personnel de l'utilisateur). Il n'est jamais transmis à un tiers.

4. Ce qui n'est jamais fait

  • Pas de transfert de données Google à des tiers, ni à un service d'analyse, ni à de la publicité, ni à un modèle d'IA hébergé.
  • Pas de vente de données, pas d'exploitation commerciale.
  • Pas de lecture de comptes autres que celui explicitement autorisé par l'utilisateur au moment du consentement.
  • Pas d'utilisation des données pour entraîner des modèles d'apprentissage automatique, généralisés ou non.

5. Combien de temps les données sont conservées

Les fichiers locaux ne survivent pas à leur utilité : l'utilisateur les supprime comme n'importe quel fichier personnel. La suppression du jeton local met fin définitivement à tout accès.

6. Comment révoquer l'accès

  • Côté Google : myaccount.google.com/permissions → sélectionner « Hermès » → « Supprimer l'accès ». Effectif immédiat.
  • Côté local : supprimer le fichier de jetons du répertoire personnel.
